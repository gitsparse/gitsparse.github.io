Licenses & liability

gitsparse just previews and repackages files that are already public on GitHub — it doesn't own, review, or relicense any of it.

Respect the original repository

Every file you browse or download through gitsparse keeps whatever license (or lack of one) its source repository has. That means crediting the original authors, following the license's terms — permissive, copyleft, or otherwise — and not presenting someone else's work as your own.

When GitHub can identify a repository's license, gitsparse shows a small badge for it and includes the LICENSE file in your download even if it lives outside the folder you asked for, specifically so that context isn't lost.

No detected license doesn't mean no rights reserved

If gitsparse doesn't show a license badge, GitHub simply couldn't detect one — that is not the same as the code being free to use. Under default copyright rules, the author retains all rights unless a license says otherwise. When in doubt, check the repository yourself or ask the author.
