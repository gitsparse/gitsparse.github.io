Download just a slice of a GitHub repo

Paste a link to any folder on GitHub and gitsparse previews the files and zips up only that subfolder — no cloning the whole repo required.

Or see it in action: Web-Dev-For-Beginners/4-typing-game

How it works

  1. Paste any GitHub folder link into the box above, or
  2. just swap the domain in your browser's address bar yourself — no need to visit GitHub first:
GitHubgithub.com/microsoft/Web-Dev-For-Beginners/tree/main/4-typing-game
↓
gitsparsegitsparse.com/microsoft/Web-Dev-For-Beginners/tree/main/4-typing-game

Works on a whole repo too — gitsparse.com/microsoft/Web-Dev-For-Beginners browses everything from the root.
